# Social-Media-Impact-on-life
A Python-based data analysis project exploring the impact of social media usage on students' sleep, academic performance, stress, and mental well-being.
Social Media Impact on Students' Lives is a data analysis project that studies how social media usage affects students' daily lives. The project analyzes factors such as daily social media usage, sleep duration, sleep quality, academic performance, stress levels, and mental well-being.
